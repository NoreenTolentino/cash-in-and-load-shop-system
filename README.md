# Cash-in and Load Shop System

A float and cash management system for GCash, Maya, and load retailers, built with HTML, CSS, and JavaScript. Record every transaction, watch each wallet balance, and close the day with a cash count.

**Live Site:** https://noreentolentino.github.io/cash-in-and-load-shop-system/

## Features

- Wallet cards for cash drawer, GCash, Maya, and load, with low-float alerts
- Cash-in, cash-out, load, bills payment, and float transfers
- Automatic fees and load margin, with a preview of how every wallet changes
- Blocks transactions when a wallet does not have enough float
- Daily profit, volume, and transaction count
- End of day count that shows whether the drawer is over or short
- Reports with a 7-day profit chart and a history of closed days
- Undo for every change and CSV export
- Data saved in the browser (localStorage)

## Run locally

The app uses ES modules, so serve the folder with a static server such as the VS Code Live Server extension.
